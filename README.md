## 📌 Sobre o projeto

Este é o meu **portfólio pessoal**, desenvolvido para apresentar minhas habilidades, projetos e evolução na área de tecnologia.

O objetivo é simples: mostrar de forma **organizada, moderna e responsiva** quem eu sou como desenvolvedor e o que já construí — servindo também como vitrine para recrutadores e oportunidades.
